Properly using Combinational Logic

29 August 2026

This post aims to explain how we can come up with combinational implementations for sequential-looking algorithms. I want to also showcase some implementations of this that I think are cool.

The theory

A good starting point is to consider the recurrence relation $$\mathbf{x_{n+1}} = f(\mathbf{x_{n}})$$ If we're considering a linear system, this would obey the powerful property $$\mathbf{x_{n+k}} = A^{k}\mathbf{x_{n}}$$ Just recognising this alone can save us a significant amount of computation.

A first implementation

A simple sequential implementation 

always_ff @(posedge clk) begin
    if (rst) begin
        state <= '0;
    end
    else begin
        state <= next_state;
    end
end
